What to do next

01Finish the toast expiry contract

The normal browser-driven lifecycle works, including hover pause and live model dismissal. However, expire still uses absolute elapsed time plus a 60-second grace period. It cannot distinguish a disconnected client from a connected reader holding a toast open.

Restrict fallback cleanup to disconnected/stale sessions, or track pause-aware expiry. Add a case with a toast paused past 65 seconds while server cleanup runs. The current lab never calls expire. Also add a real-browser success-to-success update test; the existing browser case is loading-to-success.

Queue expiry · Lab lifecycle

02Broaden interaction coverage

The previously requested live-view integration checks are now present and passing. Keep those regressions, then add Firefox/WebKit, mobile/touch and assistive-technology checks.

Focus on dialog focus return, context menus/menubars, mobile sidebar behavior, OTP paste/autofill/composition, pointer/RTL sliders and streamed or image-resized chat history. These are verification gaps, not claims that the components are broken.

29 passing Chromium cases

03Choose distribution improvements

Remaining ecosystem work: theme editor and specialized tokens; registry namespaces/authentication configuration; workspace-aware installation; migration and maintenance commands.

Prioritize whichever workflows your consumers need. These do not reduce the component coverage count; the tooling table records the existing CLI and registry capabilities alongside their limits.

04Keep deeper parity demand-driven

Optional additions include an extensible carousel plugin interface, reusable deterministic chat fixtures, MCP/agent integration and Figma resources. Exact React, Embla or Recharts API reproduction is not required for a native Gleam library.

The old requests for chips, saved transcript positioning, extra-small icon buttons, autoplay and richer slider modes are complete and removed from the backlog.

The toast fallback finding follows directly from the source and existing expiry test; the long-hover-plus-server-cleanup interaction was not reproduced in a new browser test. This update changes only the report.
